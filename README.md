## 同样是美国 ISP 代理，底层其实是两种东西

搜「美国 ISP 代理」的人，大多默认它们是一类商品。实际上市面上至少跑着两套完全不同的实现，成本、库存和适用场景差得很远。

一套是机房托管加运营商宣告。CleanProxies 在自己的常见问题里写得很直白：ISP 代理是托管在数据中心基础设施上、但注册在真实运营商名下的静态 IP，好处是拿到数据中心的速率加上住宅 IP 的信任度。这类产品库存大、能批量开、按 IP 计价，5 个起卖，一万个也能开。

另一套是在住宅物理地址上接入运营商家宽。VIRCS 的宣传文描述的做法是在加州几个城市的自有公寓里部署设备，拿到运营商的正式授权接入，每个 IP 由运营商分配给那个具体门牌。这类做法库存极薄，成本高，而且经常出现「这个运营商的号段暂时没了」的情况。

ASN 查询结果一样，不代表物理位置一样。一台放在 Ashburn 机房、由运营商 ASN 宣告的 IP，和一条挂在加州橙县公寓里的宽带，在 ipinfo、bgp.tools 里的归属信息可能都显示为同一家运营商，但你拿它去登录一个对住宅属性敏感的平台，表现未必相同。

SixTynet 属于后者这个方向的产物：官方套餐名叫 Residential，产品组路径是 at-and-t-mobility-residential，第三方测评用 ipinfo 查出来标注为住宅属性和双 ISP。官方页面本身没有解释物理接入方式，这一点如果你在意，下单前直接问客服。

## $0.75 与 $3 差在哪：四种计费口径拆开看

把不同商家的数字并排放在一起之前，先确认它们是不是同一件商品。常见的四种口径：

**按 IP 月付、量大从优。** CleanProxies 的宣传语是「低至 $0.75/IP 每月，10000 个 IP 时」，同一页面的价格卡写着 5 个 IP 每月 $15、10000 个 IP 每月 $7500。$0.75 和 $3 是同一件商品在两个采购量级上的单价。它还有一个 $4.99 买 5 个 IP、用 1 小时的付费试用。

**按 IP 月付、有最低起售量。** 这一档更接近个人和小团队的实际情况：Bright Data 10 个独享 IP 每月 $35（折合 $3.50/IP，但不能只买一个），共享 10 个是 $18，属另一个产品；Oxylabs 当前页面独享 $3/IP，Starter 档 $30/月；Decodo（原 Smartproxy）3 个独享 IP $9.99/月另加税；Webshare 独享页面展示 20 个 IP $42/月，折 $2.10/IP，可定制数量但要后台核价；IPRoyal 官网 30 天 $2.70/IP 起，另有用户后台看到 $4 的记录，这个差异没有拿到美国区结算截图，实际结账前自己点一遍；Proxy-Seller 支持买 1 个 IP，用户截图日本区 $3/月，美国区价格需要自己核。

**按流量计费。** FlashProxy 的共享 ISP 产品按 GB 计价，有量级折扣和一个按时间的 Unlimited 档，池子标称 22000+ 美国 IP、约 39ms、最高 9000 并发。

**按整台机器打包。** SixTynet 的四个套餐都是这个模式，$25 起，附带 1 个住宅 IP。

口径不同，换算方式也不同。比价格之前，先统一成「第一个月实际付出去多少钱 ÷ 你能用的独享 IP 个数」，再看每个 IP 附赠多少流量。按这个算法，SixTynet STARTER 是 $25 换 1 个 IP 加 5TB 流量，纯代理那边是 $2.70 到 $4 换 1 个 IP 加 100GB 左右的月度额度。

流量这一项差距很大，值得单独说。行业里常见的公平使用上限是每个 IP 每月 100GB：Bright Data 是 100GB/IP/月，超额可能收费；IPRoyal 是 100GB/IP/30 天；Proxy-Seller 默认约 100GB/IP、100 并发，超额后的具体速率没有公布。5TB 换算下来是 5000GB，相当于 50 个 IP 的流量额度。如果你的业务是长期挂着不关、每天跑几十 GB，纯代理的 FUP 会先撞墙。

反过来说，如果你一天只用几百 MB，那 5TB 里 99% 的额度你一辈子也用不完，多付的钱买的是机器，不是流量。

## 三分钟自己验 IP：别信商家截图，查自己的订单

拿到 IP 之后第一件事不是登录账号，是查它的归属。方法很简单：把订单里的 IP 丢进 bgp.tools，或者用 whois.cymru.com 的命令行查询，看返回的 ASN 和运营商名称。

CleanProxies 把自家的抽样结果公开列了出来，查询日期是 2026 年 11 月 3 日：Comcast 与 Xfinity 对应 AS7922（55 个样本全中）、AT&T 对应 AS7018（60/60）、Cox 对应 AS22773（5/5）、Frontier 对应 AS5650（25/25）、RCN 对应 AS6079（20/20）。

同一批数据里有一处值得注意：Verizon 的样本落到了 AS5650，而 AS5650 是 Frontier 的号。另一家厂商 IPWeb 的页面则写 Verizon 是 AS701、Charter/Spectrum 是 AS20115、CenturyLink/Lumen 是 AS209。两家口径对不上，说明运营商的 IP 段在不同渠道、不同批次里会互相流动，别背 ASN 对照表，以你自己订单查出来的结果为准。

第二个要查的是住宅属性标注。ipinfo 这类数据库会给 IP 打上 residential、ISP、双 ISP 之类的标签，平台风控拿到的也是这一类数据。SixTynet 的第三方测评里，ipinfo 把它的 IP 判为双 ISP 住宅属性，多个数据库交叉判断为原生美国 IP、家宽属性。这些是测评站点的查询结果，不是平台风控的实际判定，你自己买到手还是要重查一遍。

第三个要查的是出口能不能通。这一步最容易被跳过。有一份 2026 年 10 月 16 日的链式代理实测记录写得很清楚：入口节点单独能访问 Google，接上 ISP 之后链路失败，换成客服给的中继才通，出口核对成功、Google 返回 204；但 ChatGPT 的命令行请求收到 403，用户随后反馈浏览器能打开，完整账号功能和长期稳定性都没验证，失败原因也没查清。

能连上、能打开首页、能登录、能长期稳定用，是四件事。验收的时候一项一项过。

## 80 与 443 不开放，意味着什么

这是 SixTynet 页面里最容易被略过的一行字：因 IP 风控原因，住宅 IP 产品不开放 80 和 443 端口。

直接后果是这台机器不能拿来建站。想挂个 WordPress、放个落地页、跑个需要域名解析到 80/443 的服务，这条路堵死。

间接后果看你自己的用法。KVM 虚拟化给的是完整系统权限，代理软件自己装、端口自己定，只要避开 80 和 443，SOCKS5 或 HTTP 代理都能跑起来。但如果你要访问的目标服务强制走 443 出站，或者你打算用某些只认标准端口的客户端，就要在买之前问清楚出站方向是不是也受限。官方的措辞只说了「不开放端口」，没区分方向。

同一类限制在别处也有。VIRCS 的推广文明确写禁止建站、只提供美国 IP、不支持退款，理由是开通即产生运营商计费。这类「住宅 IP 的 VPS」几乎都有类似条款，属于行业惯例，不是某一家的问题。

套餐之间的差别只有硬件和流量，IP 完全一样。所以选型的唯一问题是：你要在这台机器上跑什么。

只挂一两个账号、用浏览器手动操作、偶尔跑个脚本，STARTER 的 2 核 2G 够用。注意 2G 内存跑现代浏览器比较紧，同时开三四个标签页加上指纹浏览器插件就容易吃满，这种情况直接上 MICRO。

要在同一台机器上开多个指纹浏览器实例、跑自动化流程、或者装 Windows 远程桌面，MICRO 的 4 核 4G 是起点。再往上，MEDIUM 和 LARGE 面向的是十几到几十个并发环境的团队，个人用户买这两档，多出来的核和内存大概率闲置。

有几类人不用考虑这个产品：

只要一个 IP 挂浏览器、不想碰服务器运维的，买纯代理更省事，$2.70 到 $4 一个月，不用装系统、不用配防火墙。

要建站的，80/443 关着，直接排除。

需要几十上百个 IP 做账号矩阵的，这种形态一个套餐给一个 IP，成本线性上升，不如按 IP 批量采购。

要做大规模轮换采集的，静态住宅 IP 本身就不适合，旋转住宅或机房代理才是对的工具，这条连卖住宅 VPS 的厂商自己都承认。

## 下单前逐项确认

这几件事问清楚再付款，能省掉大部分售后扯皮：

1. 是不是 1 个固定、独享的 IPv4，不是共享池里分出来的。
2. 当前有没有库存。页面抓取时四个套餐都显示 0 Available，这个数字会变，但说明「能下单」和「有货」是两件事。
3. 月付总价、续费价、有没有初装费，价格近期调整过几次，结算页的数字才算数。
4. 出站方向的 80 和 443 是否也受限，你的目标服务能不能正常访问。
5. 流量超额之后怎么处理，是限速、停机还是额外计费。
6. 到期是否保留原 IP，维护或迁移时会不会换 IP，有没有自动续费。
7. 退款政策。这一条资料里没有查到 SixTynet 的公开说明，别默认能退，直接问。
